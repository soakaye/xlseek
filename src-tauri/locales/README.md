# 翻訳カタログ

各言語のカタログは `en.yml`、`ja.yml` と同じ場所へ `<BCP-47 language code>.yml` として追加します。
先頭には処理内容、入出力、エラー、変更履歴の4要素コメントを記載し、プラグイン形式の `_version: 1` を設定してください。

翻訳キーは `ui.*`、`about.*`、`menu.*`、`export.*` のように領域を示す小文字の dotted key を使います。
既存キーを変更・削除せず、各言語で同じキーと `{placeholderName}` 形式の差し込み項目を定義してください。
React 側の利用者は `src/i18n.ts` の型付きキーを使い、文言を直接持たないでください。

言語を追加するときは `tests/catalog.test.ts` が要求する英語側の同一キーとプレースホルダーを用意します。
アプリが起動時にプラグインから検出できるよう `src-tauri/locales/` に置き、表示言語の選択肢を追加する場合は設定画面と OS 言語解決処理も更新してください。

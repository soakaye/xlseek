# Interface Contract: Header Comments (ヘッダコメント規約)

**Feature Branch**: `004-align-with-constitution`  
**Date**: 2026-09-26  
**Status**: Completed  

## 1. 概要
本規約は、プロジェクト憲章原則III（厳格なヘッダコメントとドキュメンテーション）を具体化し、すべてのファイル、モジュール、構造体、関数、メソッドに対する統一コメント書式を定義する。

## 2. 必須4要素 (Mandatory Elements)
すべてのヘッダコメントには、以下の4要素を必ず記載しなければならない（MUST）：

1. **処理内容の詳細な説明** (`Description`): 対象要素の責務、前提条件、処理の流れを平易かつ明瞭に説明。
2. **引数・戻り値の型と各説明** (`Parameters and Return Value`): 各引数の用途と型、戻り値の型と内容。
3. **起こり得るエラー、Result/Option の扱い、または panic / 例外の発生条件** (`Errors & Panics`): エラー発生契機、返却されるエラーの内容、パニックを発生させない旨の保証。
4. **変更履歴** (`Revision History`): バージョン、作成日、作成者（AI Agentまたは開発者名）、修正内容。

## 3. 言語別標準構文

### 3.1. Rust ファイル・モジュールレベル (`//!`)
```rust
//! # モジュール名: search::engine
//!
//! ## 処理内容
//! Excelブックの並列走査、進捗イベント通知、およびキャンセル制御を行うコア検索エンジンを提供する。
//!
//! ## 変更履歴
//! - v1.0.0 (2026-09-26, AI Agent): 初版策定 / 憲章準拠ヘッダ追加。
```

### 3.2. Rust 構造体・関数・メソッドレベル (`///`)
```rust
/// ## 処理内容
/// 指定された検索クエリに基づき、対象ディレクトリ配下のExcelファイルをマルチスレッドで並列検索する。
///
/// ## 引数
/// - `app_handle`: `AppHandle` - 進捗イベントをフロントエンドへ通知するためのTauriハンドル
/// - `query`: `SearchQuery` - 検索キーワード、対象パス、拡張子等の検索条件
///
/// ## 戻り値
/// - `Result<Vec<SearchMatch>, String>`: 検索成功時は一致アイテム一覧、失敗時は日本語エラーメッセージ
///
/// ## エラー / 例外発生条件
/// - 対象ディレクトリが存在しない場合、または正規表現が不正な場合に `Err` を返却する。
/// - 不可逆なパニックは発生しない。
///
/// ## 変更履歴
/// - v1.0.0 (2026-09-26, AI Agent): 初版策定 / 憲章準拠。
```

### 3.3. TypeScript ファイルレベル (`/** ... */`)
```typescript
/**
 * @fileoverview 結果テーブルコンポーネント (ResultTable)
 *
 * ## 処理内容
 * 検索にヒットしたセルの一覧を仮想スクロールで高速表示し、プレビュー選択や外部アプリ起動を提供する。
 *
 * ## 変更履歴
 * - v1.0.0 (2026-09-26, AI Agent): 初版策定 / 憲章準拠。
 */
```

### 3.4. TypeScript コンポーネント・関数レベル (`/** ... */`)
```typescript
/**
 * ## 処理内容
 * 検索進捗イベントを購読し、検索開始・中断・結果更新を管理するカスタムフック。
 *
 * ## 引数
 * @param onSearchCompleted - 検索完了時に呼び出されるコールバック関数
 *
 * ## 戻り値
 * @returns 検索状態、進捗状況、および操作関数を含むオブジェクト
 *
 * ## エラー / 例外発生条件
 * Tauri IPC通信エラー発生時はエラー状態を更新し、トーストで日本語通知を行う。例外は外部へスローしない。
 *
 * ## 変更履歴
 * - v1.0.0 (2026-09-26, AI Agent): 初版策定 / 憲章準拠。
 */
```

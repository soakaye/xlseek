# Shape Search Contract

## 検索要求

既存の `start_search` に渡す `SearchQuery` に `include_shape: boolean` を追加する。省略時は `true` とし、数式オプションとは独立する。画面の「Shape 内テキスト」トグルで値を設定し、`false` では描画データを読み取らない。既存の検索語、正規表現、大文字・小文字、対象形式、非表示シートの条件はそのまま適用する。

## 検索結果イベント

既存の `search-match` イベントの結果オブジェクトを拡張する。

| 項目 | Shape 結果での値 | 既存結果での値 |
|---|---|---|
| `match_type` | `Shape` | 既存の種別 |
| `shape_name` | グループ経路を含む図形名 | `null` |
| `sheet_hidden` | シートの実際の可視状態 | シートの実際の可視状態 |
| `file_name`, `full_path`, `sheet_name` | Shape の所在 | 従来どおり |
| `full_content` | Shape 内の全文 | 従来どおり |
| `snippet` | 一致を含む安全な表示用断片 | 従来どおり |
| `formula` | `null` | 従来どおり |
| `cell_address` | アンカー取得時のみ実際のセル番地。それ以外は空文字列 | 従来どおり |
| `row_index`, `col_index` | アンカー取得時のみ実際の1始まり位置。取得不能時は内部値 0 | 従来どおり |

図形ごとに1つのイベントを送る。同一図形の複数一致を重複送信せず、異なる子図形は個別の結果とする。未信頼の Shape 文字列は HTML として解釈させない。大量マッチ時の IPC 過負荷を防ぐため、イベントは最大50件または25ms間隔のバッチ配列（`SearchMatch[]`）として配信される。

## 画面操作

- 結果一覧は `Shape` の種別を日英で表示し、Shape 名を確認・絞り込みできる。
- **Shape プレビュー表示**:
  - **アンカーセル情報を持つ Shape (`row_index > 0 && col_index > 0`)**: アンカー位置を中心としたセルプレビュー要求（`get_cell_preview`）を実行し、通常セルと同様に数式バーおよびスプレッドシートグリッドを表示する。
  - **アンカーセル情報を持たない Shape (`row_index === 0 || col_index === 0`)**: セルプレビュー要求は送信せず、プレビュー領域に図形名バッジ、テキスト全文、および「図形内テキストのためセル配置情報はありません (`ui.PREVIEW_SHAPE_NO_ANCHOR`)」の専用ガイダンスカードを表示し、空欄表示となることを防止する。
- 実際のアンカーがある場合だけセル番地を補助情報として示し、Shape の文字列をセル値と誤認させない。
- 非表示シートの Shape は `include_hidden` が真の時だけ返し、種別は `Shape` のまま可視状態を別表示する。

## CSV / Excel 出力

既存の列は維持し、Shape 名の独立列を追加する。Shape 結果の `Shape 名` 列に表示名、`セル位置` 列には取得できた実際のアンカーのみ、`一致内容` 列に全文、`一致種別` 列に選択言語の Shape ラベルを出す。セル結果の `Shape 名` 列は空にする。両形式の列順と翻訳キーを一致させる。

## 失敗と中断

破損した図形1件は他の図形・セルの結果を消さない。ファイル自体を開けない場合は既存のファイルエラー経路へ渡す。キャンセル後のイベント配送と画面表示は既存検索のルールに従う。Shape 検索オフでは、破損した描画データがあってもセル検索の結果へ影響させない。

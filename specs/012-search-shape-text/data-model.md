# Data Model: Shape 内テキスト検索

## 検索条件

既存の `SearchQuery` に `include_shape: bool` を追加する。既定値は `true`。画面の独立したトグルと Tauri 検索要求で同じ値を使う。`include_formula`、`include_comment` から独立し、`false` の時は描画データを読まない。

## 抽出した Shape テキスト

| 属性 | 型 | 制約 |
|---|---|---|
| file_path | パス | 現在検索しているファイル |
| sheet_name | 文字列 | 実際に所属するワークシート名 |
| shape_path | 文字列 | グループ名から子図形名までの表示用経路。通常図形は図形名 |
| shape_id | 文字列 | 図形内の対応付け用。表示名が重複しても図形を区別する |
| text | 文字列 | 図形内の文字を順序どおり結合。空文字は検索結果にしない |
| anchor | 任意の行・列 | 取得できた場合のみ 1 始まりのセル位置に変換 |
| sheet_hidden | 真偽値 | シートのメタデータに基づく可視状態 |

グループは子図形を包含するが、検索結果の単位にはしない。子図形ごとに1つの抽出値を作る。名前が欠ける図形は図形 ID に基づく安定した表示名を使う。描画データが壊れた図形はその図形だけをスキップし、他の結果を維持する。

## 検索結果

既存の `SearchMatch` に `match_type = Shape`、`shape_name: Option<String>`、`sheet_hidden: bool` を追加する。Shape の時は `shape_name` が必須、セル値・数式等では `None` とする。`full_content` は Shape の全文、`snippet` は一致箇所を含む表示用断片、`formula` は `None`。

実際のアンカーを取得できた場合のみ既存の `cell_address` と行・列へ反映する。取得できない場合、`cell_address` と `col_name` は空、`row_index` と `col_index` は内部値 0 とし、画面・出力にはセル番地や行列番号として表示しない。Shape 結果の選択時はセルプレビュー要求を送らず、結果にある Shape 名、シート名、全文を表示する。

既存の画面内結果 ID は Shape 結果にも一意に付与する。同じ図形に検索語が複数回あっても1件とし、別の子図形は同じ文字列でも別件にする。

## 状態と検証

1. 検索開始時の `include_shape` によって Shape 抽出を行うか決める。
2. ファイル単位でシートの可視状態を確認し、対象シートの Shape 文字列を抽出する。
3. 既存の検索語・大文字小文字・正規表現の一致判定で各 Shape を評価する。
4. 一致した図形を結果へ合流し、画面の一覧・選択詳細・出力へ同じ結果モデルを渡す。
5. 中断要求時は新しい図形の走査を止め、既存の中断処理に取得済み結果を返す。

入力が壊れている場合は範囲外長さ、過大な展開量、無効な文字列を安全に扱い、検索全体をパニックさせない。Shape 名や本文は検索対象ファイルから来る未信頼文字列として画面で安全に描画する。

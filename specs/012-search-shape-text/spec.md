# Feature Specification: Excel Shape 内テキストの検索

**Feature Branch**: `012-search-shape-text`

**Created**: 2026-09-27

**Status**: Draft

**Input**: User description: "Excel Shape中のテキストも値・数式と同様に検索対象に含め検索する。数式と同様にオプション指定が有効な場合のみ検索する。"

## Clarifications

### Session 2026-09-27

- Q: グループ化された図形の中にある文字も検索対象に含めますか？ → A: グループ内の各図形を個別に検索する。
- Q: Shape 内テキスト検索は、現在対応している4形式（`.xlsx`、`.xlsm`、`.xls`、`.xlsb`）すべてで必須ですか？ → A: 4形式すべてで必須。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Shape 内の文字を見つける (Priority: P1)

利用者は「Shape 内テキスト」オプションを有効にして検索し、テキストボックスや図形に書かれた文字を、セル値や数式と同じ結果一覧で確認できる。

**Why this priority**: セル外の注記や見出しを見落とさずに済むため。

**Independent Test**: セルにはない語をテキストボックスと図形に記入して検索し、それぞれの結果を確認する。

**Acceptance Scenarios**:

1. **Given** 対象シートのテキストボックスと図形に検索語がある、**When** Shape 内テキスト検索を有効にする、**Then** それぞれが個別の結果に現れ、ファイル、シート、Shape、一致文字列を確認できる。
2. **Given** 同じ語がセル値、数式、Shape にある、**When** 対応する検索オプションを有効にする、**Then** 各結果の種別を区別できる。

---

### User Story 2 - Shape 検索を切り替える (Priority: P1)

利用者は数式検索と独立したオプションで Shape 検索を切り替え、必要な結果だけを得られる。

**Why this priority**: 利用者が意図した検索対象に絞れるため。

**Independent Test**: Shape とセルに同じ語を置き、Shape のオプションだけを切り替えて結果を比較する。

**Acceptance Scenarios**:

1. **Given** Shape 内にのみ検索語がある、**When** Shape 検索を無効にする、**Then** ヒットは 0 件になる。
2. **Given** Shape とセル値に同じ検索語がある、**When** Shape 検索を無効にする、**Then** セル値の結果は残り、Shape の結果だけが除外される。
3. **Given** 数式検索が無効である、**When** Shape 検索を有効にする、**Then** Shape は検索され、数式は検索されない。

---

### User Story 3 - 既存の検索条件と結果出力を使う (Priority: P2)

利用者は大文字・小文字、正規表現、非表示シートの検索条件を Shape にも適用し、結果を既存の出力機能で共有できる。

**Why this priority**: 対象によって検索条件や結果の扱いが変わる混乱を避けるため。

**Independent Test**: 条件の異なる Shape を検索し、一覧と出力先の双方を確認する。

**Acceptance Scenarios**:

1. **Given** 大文字・小文字が異なる Shape の文字列がある、**When** 大文字・小文字を区別する、**Then** 指定した表記に一致する Shape だけがヒットする。
2. **Given** 正規表現に一致する Shape の文字列がある、**When** 正規表現検索を有効にする、**Then** Shape にも同じ式が適用される。
3. **Given** 非表示シート上に検索語を含む Shape がある、**When** 非表示シート検索を無効にする、**Then** その Shape はヒットせず、有効にするとヒットする。
4. **Given** Shape の結果が表示されている、**When** 検索結果を出力する、**Then** Shape の所在、種別、一致内容を出力先でも確認できる。

### Edge Cases

- 空の Shape は結果を作らない。複数の Shape に同じ文字列がある場合は Shape ごとに結果を作る。
- 1 つの Shape に検索語が複数回現れても、1 回の検索につきその Shape の結果は 1 件とする。
- グループ内の複数の図形に同じ検索語がある場合、図形ごとに 1 件ずつ結果を作る。
- Shape がセルに重なっていても、セル値と Shape は別々の結果とする。
- セルに結び付いた位置を特定できなくても、Shape 名とシート名で所在を示す。
- 画像内の文字とグラフ内のラベルは対象に含めない。
- 読み取れない Shape があっても検索全体を異常終了させず、読み取れる対象の結果を保つ。
- 検索中断時は Shape の走査も停止し、取得済みの結果を既存の中断時の扱いに従って表示する。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: アプリは「Shape 内テキスト」の独立したオン・オフ項目を提供しなければならない。初期状態はオンとし、数式検索の切替で状態が変わってはならない。
- **FR-002**: アプリは項目がオンの時に限り、選択された対象ファイルのテキストボックスと文字を持つ図形を検索しなければならない。`.xlsx`、`.xlsm`、`.xls`、`.xlsb` の全形式に対応し、グループ内の図形も個別の対象とする。オフでは Shape に由来する結果を返してはならない。
- **FR-003**: アプリは Shape にもセル値・数式と同じ検索語、大文字・小文字、正規表現の条件を適用しなければならない。
- **FR-004**: アプリは非表示シート検索がオフの時、そのシート内の Shape を検索対象から外さなければならない。
- **FR-005**: アプリは一致した Shape ごとに 1 件の結果を表示し、セル値・数式と区別できる種別、ファイル名とパス、シート名、Shape 名、一致箇所を含む文字列を確認できるようにしなければならない。
- **FR-006**: アプリは Shape の結果を選択した時、文字列全体と所在を表示しなければならない。位置が得られない場合、架空のセル番地を表示してはならない。
- **FR-007**: アプリは Shape の結果を既存の検索結果出力に含め、画面上の所在、種別、文字列を出力先でも判別できるようにしなければならない。
- **FR-008**: アプリは読み取れない Shape や検索中断に遭遇しても、操作可能な状態と取得済みの結果を維持しなければならない。
- **FR-009**: アプリは Shape 検索の項目名と結果種別を、選択された表示言語で示さなければならない。

### Key Entities

- **Shape 検索設定**: Shape 内テキストを検索するかを指定する独立したオン・オフ値。
- **Shape テキスト**: テキストボックスまたは文字を持つ図形の文字列。グループ内でも各図形を個別に扱い、所属ファイル、シート、Shape 名、取得可能な位置を持つ。
- **Shape 検索結果**: 一致した Shape を表す結果。種別、所在、一致を含む文字列、文字列全体を持つ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 4 種類の対象ファイル形式の検証用ブックで、テキストボックス、通常の図形、グループ内の各図形の検索語を、Shape 検索がオンの時に 100% 表示し、オフの時に 0 件とする。
- **SC-002**: セル値、数式、Shape に同じ語を置いた検証用ブックで、オプションの切替によって意図しない種別の結果が増減する件数を 0 件とする。
- **SC-003**: Shape の結果を選んでから 3 操作以内に、ファイル、シート、Shape、一致文字列の全てを確認できる。
- **SC-004**: Shape の結果を含む検索結果を出力した時、画面上の Shape の結果の欠落を 0 件とする。
- **SC-005**: 読み取れない Shape を含む検証用ブックで検索全体の異常終了を 0 件とし、読み取れる対象の結果を全件表示する。
- **SC-006**: 各ファイルに検索語と一致する Shape を1件以上含む、ローカル保存の100ファイル・合計100 MB の検証用フォルダで、Shape 検索開始から画面に最初の結果が表示されるまでを、計測環境を記録した同一端末で測定して10秒以内とし、検索中も画面を操作できる。

## Assumptions

- 「Shape」はシート上のテキストボックスと文字を持つ図形を指す。画像内の文字、グラフ内の文字、コメントは含まない。
- 利用者が検索対象として選択したファイル形式だけを検索する。
- Shape 検索の初期状態は既存の数式検索と同じくオンとする。設定の永続保存は今回の対象外とする。
- Shape の位置情報がない場合でも、Shape 名と所属シートで結果を識別できる。
- 検索と結果出力は端末内で完結し、ブックの内容を外部に送信しない。

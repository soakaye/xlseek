# CLI契約

## コマンド

```text
exlgrep-cli --path PATH --query TEXT --format csv|xlsx --output PATH [OPTIONS]
exlgrep-cli --help [--language ja|en]
```

Windowsの実行ファイルは `exlgrep-cli.exe`。サブコマンドや対話的な質問はない。

| オプション | 値 | 必須・既定値 |
|---|---|---|
| --path | 検索ファイルまたはフォルダー | 必須 |
| --query | 検索文字列または正規表現 | 必須、空文字列は禁止 |
| --format | csv / xlsx | 必須 |
| --output | 保存先ファイルパス | 必須 |
| --match-case | true / false | false |
| --regex | true / false | false |
| --values | true / false | true |
| --formulas | true / false | true |
| --comments | true / false | true |
| --shapes | true / false | false |
| --hidden-sheets | true / false | false |
| --extensions | カンマ区切りの拡張子 | .xlsx,.xlsm,.xlsb,.xls |
| --language | ja / en | ja |
| --overwrite | 値なしのフラグ | 未指定では上書き禁止 |
| --help / -h | 値なしのフラグ | languageだけ併用可能、検索・保存なし |

値を取るオプションは `--name VALUE` と `--name=VALUE` の両方を受け付ける。検索語の空白は保持し、値がハイフンで始まっても値として扱う。真偽値は表にある小文字表記だけを受け付ける。未知・重複オプション、値不足、位置引数、不正値は入力エラーとする。ヘルプは必須引数を必要としない。`--help` と `-h` は同じオプションとして扱い、任意の `--language ja|en`（`--language=en` も可）だけを併用できる。順序は問わない。他のオプション、未知・重複指定、言語の値不足・不正値は終了コード2とし、検索・保存は開始しない。

## 入力・検索条件

- 1回の実行に指定する検索パスは1つ。フォルダーは再帰検索し、下位のシンボリックリンクは辿らない。`~$` から始まる一時ブックは除外する。
- 相対パスは現在の作業ディレクトリを基準に解決する。ホーム省略は既存のパス解決処理を利用し、最終パスは絶対パスにする。共有コアの文字列パス契約に合わせ、非Unicodeの引数は明示的な入力エラーにする。
- extensionsの前後の空白と先頭のドット有無を正規化し、大小文字は区別しない。4形式以外、空の一覧、単一ファイルの拡張子が対象外の場合は入力エラー。
- 値・数式・コメント・Shapeをすべてfalseにした場合は入力エラー。hidden-sheetsは検索種別ではなく対象シートの範囲指定である。
- 省略オプションは表の固定値を使う。GUIの保存済み設定は読み込まない。
- 非表示シートの設定は、値・数式・コメント・Shapeのすべてに適用する。

## 結果ファイル

CSVは既存出力と同じBOM付きUTF-8、Excelはxlsx。列は既存 `EXPORT_HEADER_KEYS` の9列（ID、ファイル名、パス、シート名、セル、Shape名、一致種別、一致内容、数式）を維持し、言語指定で見出しと一致種別を切り替える。0件でも見出しを出力する。並列検索のため行順とIDの固定順は保証しない。

出力拡張子は形式と一致しなければならない。既存の親フォルダーだけを使用し、フォルダーを自動作成しない。

既存出力は `--overwrite` がなければ拒否する。対話的確認はしない。検索入力への上書きは、別名ハードリンクを含め `--overwrite` があっても拒否する。既存の出力xlsxが検索フォルダー内の対象ファイルに該当する場合も入力として保護する。出力先自身のシンボリックリンクと、開始時・入力検出時・公開直前の検査で確認した出力先の作成・置換は拒否する。

入力とパス構成は実行中に他プロセスが変更しない前提とする。既定の上書き禁止ではhard_linkによる公開を使い、公開時に出力が出現しても既存ファイルを置き換えず失敗する。`--overwrite` は保存先と親ディレクトリを他プロセスが変更しない環境で使用する。公開直前の同一性検査とrenameは一体の操作ではなく、その間に行われる第三者の変更を拒否する保証はない。明示上書きで同時変更を排除するロック機構は提供しない。

検索後に出力親の一時領域へ保存し、完成したファイルだけを公開する。保存・公開に失敗した場合、既存出力は削除しない。上書きなしの公開に必要なハードリンクを扱えないファイルシステムでは保存エラーとする。Excelの行数・文字列長など既存出力ライブラリの上限を超えた場合も、無言の切り捨てではなく保存エラーとする。

## 標準出力・標準エラー・終了コード

stdoutはヘルプまたは完了の要約（走査数・読取り可能数・一致件数・問題数・保存先）。stderrは対象パスと問題理由、入力不備、保存失敗。jaが既定で、language=enなら英語。CSVデータをstdoutへ流すモードは提供しない。

| コード | 意味 | 結果ファイル |
|---|---|---|
| 0 | 全件成功、空フォルダー、正常な0件一致、ヘルプ | 検索では保存。ヘルプでは作成しない |
| 1 | 一部ブック・シート・抽出部品・下位フォルダーの問題を通知し、検索と保存を完走 | 利用可能な結果を保存 |
| 2 | 入力不備、ルート検索不能、入出力衝突、検索全体の異常、保存・公開失敗 | 新しい成功結果として公開しない |
| 2 | 対象ブックが1件以上あるが、すべて開けなかった | 見出しだけのファイルを保存し、検索失敗を明示 |

保存失敗は部分失敗より優先して2とする。全ブック読取り失敗と、正常に読めたうえでの0件一致を混同しない。検索中のファイルごとの問題はスキップして他の入力を検索する。

## 共通コアとの互換性

既存GUI向けSearchQueryとScanProgressの必須フィールド・イベントは維持する。`include_value` を省略した既存要求はtrueとなる。旧 `execute_search` と `parse_and_search_file` の公開契約を維持し、詳細処理を呼ぶラッパーにする。CLIは詳細結果を使い、GUIも同じ検索ルールで結果を取得する。

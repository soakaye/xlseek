# Research: 検索履歴とディレクトリ補完

## 履歴の保存場所

- **Decision**: `src/locale-core.ts` と同じ `localStorage` を用い、保存件数・検索テキスト履歴・ディレクトリ履歴を 1 つの値に保存する。起動時に保存値の型と件数を検証し、不正な値は初期値へ戻す。書込失敗時も画面内の検索を続け、既存の通知手段で知らせる。
- **Rationale**: 既存アプリに端末内設定の保存パターンがある。単一値なら件数変更時の切り詰めと 0 件での消去をまとめて保存できる。
- **Alternatives considered**: 新しい保存プラグインは依存と権限を増やす。複数キーは部分書込みによる不整合を扱う必要がある。

## 履歴を追加する時点

- **Decision**: フロントエンドの必須入力検証と、バックエンドのディレクトリ・正規表現検証を通って `start_search` が成功を返した直後に、入力欄の元の文字列を追加する。結果ゼロ件、中断、実行中の失敗では取り消さない。
- **Rationale**: 現在の `start_search` は `spawn_blocking` 後すぐ成功を返し、`search/engine.rs` のパス検証と正規表現のコンパイルはその後に走る。検証をコマンド受付前に行うと、仕様の「開始できた検索」と保存条件が一致する。読取確認には `read_dir` の結果を使い、権限拒否と不存在を区別する。UNC 共有へのアクセスが待機する場合に備え、ファイルシステム操作はブロッキング用スレッドで実行してからコマンドを返す。
- **Alternatives considered**: 画面だけのパス検証はバックエンドとの判定差を残す。検索完了イベントで保存する方式は中断・失敗時も保存する仕様に反する。

## パス解決と補完

- **Decision**: Rust の標準ファイルシステム機能と Tauri 組み込みのホームディレクトリ取得 API を使う。OS に応じた絶対パスとホーム省略表記を補完対象とし、親直下から前方一致するディレクトリを列挙する。末尾が区切り文字ならそのディレクトリを親として空の接頭辞で列挙する。結果は整列後に一定件数以内へ切り詰め、読めない親は空配列とする。ホーム省略表記の候補と履歴ではその接頭辞を保ち、検索エンジンへ渡す際に実パスへ解決する。検索前の読取確認と補完の列挙はブロッキング用スレッドで実行し、画面を止めない。
- **Rationale**: 既存依存で必要な操作を完結でき、画面のファイルシステム権限を増やさない。列挙はバックグラウンドで行い、入力の連続変更時には古い応答を破棄する。
- **Alternatives considered**: ファイルシステムプラグインは新しい権限と依存を要する。ブラウザの入力補完だけでは実在するフォルダを列挙できない。全階層の探索は遅く、仕様範囲を超える。

Windows では `Path::is_absolute` がドライブ付きパスと UNC 共有パスを認識し、`C:folder` と `\folder` を絶対パスと見なさない。[Rust 標準ライブラリ](https://doc.rust-lang.org/std/path/struct.Path.html)と[Microsoft のパス規則](https://learn.microsoft.com/windows/desktop/FileIO/naming-a-file)に従い、ドライブ相対・ルート相対を補完対象外にする。さらに [`Prefix::kind`](https://doc.rust-lang.org/std/path/enum.Prefix.html) を確認し、デバイスパスと拡張長パスを除外する。Windows の `~\` もホームへ解決し、未接続の UNC 共有は候補を返さない。ネットワーク先の列挙は遅くなる場合があるため、画面は待たず、入力変更後の古い応答を破棄する。

## 画面操作と検証

- **Decision**: 各入力欄の履歴専用ボタンで履歴を開き、ディレクトリ入力中は補完候補を表示する。補完候補と履歴は同時に開かない。既存の IME ガードを維持し、変換中以外で矢印・Enter・Escape を扱う。設定には 0～50 の整数入力を追加する。
- **Rationale**: 既存 `SearchBar.tsx` に入力・フォルダ選択・ドラッグ＆ドロップの操作が集まっている。`SettingsDialog.tsx` には既存の設定導線がある。
- **Alternatives considered**: 履歴と補完を混ぜた 1 つのリストは選択対象が曖昧になる。新しい設定画面は導線を重複させる。

## 未解決事項

なし。極端に大きい親ディレクトリの列挙時間は検証時に実測し、必要になった場合だけ追加の制限を検討する。

## 1. コマンド構文 (Command Syntax)

```bash
exlgrep-cli [OPTIONS] <KEYWORD> [INPUT_PATHS...]
```

## 2. コマンドラインオプション一覧 (Options Specification)

| 長形式オプション | 短形式 | パラメータ | 既定値 | 説明 |
|:---|:---:|:---:|:---:|:---|
| `--output` | `-o` | `<PATH>` | なし (標準出力) | 出力先ファイルパス（省略時は標準出力へ直接CSV出力） |
| `--format` | `-f` | `csv\|xlsx` | `csv` | 出力フォーマット（拡張子からの自動推落も可能） |
| `--match-case` | `-c` | なし | 無効 | 大文字小文字を区別する |
| `--entire-cell` | `-m` | なし | 無効 | セル全体の一致を要求する |
| `--regex` | `-r` | なし | 無効 | 正規表現検索を行う |
| `--formulas` | `-u` | なし | 無効 | 数式文字列を検索対象に含める |
| `--comments` | `-n` | なし | 無効 | セルコメント（メモ）を検索対象に含める |
| `--shapes` | `-s` | なし | 無効 | 図形内テキストを検索対象に含める |
| `--hidden-sheets`| `-d` | なし | 無効 | 非表示シートを検索対象に含める |
| `--extensions` | `-e` | `<EXT,EXT>` | `.xlsx,.xlsm,.xls,.xlsb` | 対象拡張子のカンマ区切り指定 |
| `--language` | `-l` | `ja\|en` | `ja` | 出力・メッセージの言語指定 |
| `--overwrite` | `-w` | なし | 無効 | 出力先既存ファイルの上書きを許可する |
| `--help` | `-h` | なし | - | ヘルプメッセージを表示して終了する |

## 3. 終了ステータス契約 (Exit Code Contract)

| 終了コード | 定数値 | 条件 | 標準出力 / 標準エラー |
|:---:|:---:|:---|:---|
| `0` | `CLI_EXIT_SUCCESS` | 正常完了（一致 0 件を含む）、または `--help` / `-h` 表示 | 出力先に結果保存（または標準出力CSV） |
| `1` | `CLI_EXIT_PARTIAL` | 1 つ以上のファイルで読み取り・解析失敗が発生したが、残りのファイルから検索結果を取得・出力できた場合 | 標準エラーに警告/失敗一覧、出力先には取得できた結果を保存 |
| `2` | `CLI_EXIT_FAILURE` | 引数不正、検索ルート走査不能、出力先上書き禁止/保存失敗、または全対象ファイルの読み取りが失敗した場合 | 標準エラーにエラー内容を出力 |

## 4. 入出力保護契約 (I/O Safety Contract)

1. **自己上書き防止**: 入力対象ファイルパスと出力先ファイルパスが同一の場合、検索を開始せずにエラー（終了コード 2）とする。
2. **安全な書き込み**: ファイル出力時は一時ファイル（`.tmp`）に書き込みを行い、正常完了後にアトミックにリネーム・公開する。
3. **標準出力モードの純粋性**: 出力先（`--output`）が指定されず標準出力へストリーミングされる場合、サマリーテキスト等の人間向け案内文言は抑制され、純粋な CSV テキストのみが出力される。

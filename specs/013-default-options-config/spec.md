### Session 2026-09-28

- Q: 設定ダイアログでデフォルト検索オプションを変更した際、現在メイン画面の検索バーに表示されているオプション状態にも即座に連動して同期・更新しますか？ → A: 設定保存時に現在の検索バーのオプション状態も即座に新しいデフォルト値で更新する (Option A)。
- Q: 設定ダイアログ内に「デフォルト値にリセット」ボタンを配置し、ワンクリックで公式規定値に戻せる機能を設けますか？ → A: 設定ダイアログ内に「デフォルトに戻す」ボタンを配置し、出荷時既定値に復元可能とする (Option A)。

## ユーザーシナリオ & テスト *(必須)*

### ユーザーストーリー 1 - デフォルト検索オプションのカスタマイズと次回起動時への反映 (優先度: P1)

ユーザーは設定ダイアログから、検索時の初期オプション（大文字/小文字区別、正規表現、数式、Shape内テキスト、コメント/メモ、非表示シート、対象拡張子）の各デフォルト値を設定・保存でき、次回アプリケーション起動時および設定保存時にそれらの好みのデフォルト状態が現在の検索画面および次回起動時に自動で適用される。また、必要に応じてワンクリックで公式規定の初期値へリセットできる。

**この優先度である理由**: 日常的に利用するユーザーが起動するたびに好みの検索オプション（例: Shape内テキストの除外や数式検索のONなど）を手動で変更する手間をなくし、基本体験を大幅に向上させるため。

**独立テスト方法**: 
1. アプリケーションを起動し、設定画面を開く。
2. 検索デフォルト設定（例: 「数式」をOFF、「非表示シート」をONなど）を変更して保存する。
3. 設定ダイアログを閉じた直後にメイン画面の検索バーのオプションが即座に反映され、さらにアプリケーション再起動時にも保存した設定通りに初期化されることを確認する。
4. 設定画面で「デフォルトに戻す」ボタンを押下した際、すべてのオプションが出荷時初期値へ正しくリセットされることを確認する。

**受入シナリオ**:

1. **前提**: アプリケーションを初期状態で起動している。
   **もし**: 設定ダイアログを開いた場合、
   **ならば**: 現在のデフォルト検索オプション一覧（大文字/小文字区別: OFF、正規表現: OFF、数式: ON、Shape内テキスト: OFF、コメント/メモ: ON、非表示シート: OFF、対象拡張子: .xlsx, .xlsm, .xlsb, .xls）が表示される。
2. **前提**: 設定ダイアログで任意のデフォルト検索オプション（例: Shape内テキストをON、数式をOFF）に変更して保存した。
   **もし**: 設定保存が完了した、またはアプリケーションを再起動した場合、
   **ならば**: 変更したデフォルトオプション値が現在の検索バーのオプション状態および次回起動時の初期状態として即座に反映される。
3. **前提**: ユーザーが設定画面で対象拡張子の選択状態を変更（例: .xlsb をデフォルト対象から除外）して保存した。
   **もし**: 設定を保存した、または次回起動した場合、
   **ならば**: 検索バーの拡張子トグルが指定された拡張子セット（.xlsx, .xlsm, .xls のみ有効）へ即座に更新される。
4. **前提**: 設定画面でオプションの値を変更した状態である。
   **もし**: 「デフォルトに戻す」ボタンを押下した場合、
   **ならば**: 全オプションの表示が公式規定値（大文字小文字=OFF, 正規表現=OFF, 数式=ON, Shape=OFF, コメント=ON, 非表示シート=OFF, 拡張子=.xlsx/.xlsm/.xlsb/.xls）に復元される。

### ユーザーストーリー 2 - 検索結果のCSV出力およびExcel出力（保存先ダイアログによる明示的保存） (優先度: P2)

ユーザーは検索完了後、検索結果一覧をCSVファイルまたはExcelファイルとしてエクスポートでき、OS標準のファイル保存ダイアログから任意の保存先ディレクトリおよびファイル名を指定して確実に保存できる。

**この優先度である理由**: 検索した結果を外部ツールやレポート共有用に出力・保存することは、実務上の分析・共有において必須のワークフローであるため。

**独立テスト方法**:
1. 検索を実行してヒット結果を取得する。
2. ステータスバーの「CSV出力」または「Excel出力」をクリックする。
3. OS標準の保存ダイアログが表示され、保存先フォルダとファイル名を指定して保存を実行する。
4. 指定したパスに検索結果が正しく書き込まれ、完了メッセージが通知されることを確認する。

**受入シナリオ**:

1. **前提**: 検索結果が1件以上表示されている。
   **もし**: ステータスバーの「CSV出力」ボタンを押下した場合、
   **ならば**: ファイル保存ダイアログが開き、デフォルトファイル名（日付入り）が提示され、ユーザーが保存場所を決定して保存できる。
2. **前提**: 検索結果が1件以上表示されている。
   **もし**: ステータスバーの「Excel出力」ボタンを押下した場合、
   **ならば**: ファイル保存ダイアログが開き、.xlsx 形式での保存先を選択でき、正常にファイルが出力される。
3. **前提**: ファイル保存ダイアログが開いている。
   **もし**: ユーザーがダイアログの「キャンセル」を押下した場合、
   **ならば**: ファイルの書き込みは行われず、エラーとならずに元の画面状態を維持する。

### エッジケース

- **保存データの破損・不正値**: 保存された設定ファイルまたは永続化ストレージの値が破損または型不一致の場合、規定のフォールバック値（大文字小文字=OFF, 正規表現=OFF, 数式=ON, Shape=OFF, コメント=ON, 非表示シート=OFF, 拡張子=.xlsx/.xlsm/.xlsb/.xls）を自動復元して正常起動すること。
- **検索対象拡張子が全解除された場合**: 設定画面で全ての拡張子のチェックを外そうとした場合、最低1つ以上の拡張子を選択する必要がある旨のバリデーション警告を行い、空状態での保存を防止すること。
- **エクスポート結果が0件の場合**: 検索結果が0件の状態でエクスポートボタンが押された場合、保存ダイアログは開かず、対象データが存在しない旨を分かりやすくユーザーに通知すること。
- **書き込み権限のない場所への保存**: 保存ダイアログで書き込み権限のないディレクトリが選択された場合、エラーダイアログまたはトースト通知で失敗理由を明確に伝え、アプリがクラッシュしないこと。

## 要件 (Requirements) *(必須)*

### 機能要件 (Functional Requirements)

- **FR-001**: システムは、以下の検索オプションに対するデフォルト初期値を提供しなければならない (MUST)。
  - 大文字/小文字を区別 (Match Case): 既定値 OFF
  - 正規表現 (Use Regular Expression): 既定値 OFF
  - 数式 (Include Formula): 既定値 ON
  - Shape内テキスト (Include Shape Text): 既定値 OFF
  - コメント/メモ (Include Comments/Notes): 既定値 ON
  - 非表示シート (Include Hidden Sheets): 既定値 OFF
  - 対象拡張子 (Target Extensions): 既定値 .xlsx, .xlsm, .xlsb, .xls (全有効)
- **FR-002**: システムは、設定ダイアログ内に「デフォルト検索オプション」の設定項目群を提供し、各オプションのON/OFFおよび対象拡張子の選択を変更可能にしなければならない (MUST)。
- **FR-003**: システムは、ユーザーが変更したデフォルトオプション設定をローカル環境へ安全に永続化しなければならない (MUST)。
- **FR-004**: システムは、デフォルトオプション設定の保存時および次回起動時・検索条件の初期化時に、永続化されたデフォルトオプション設定を読み込み、現在の検索バーおよび初期状態へ即座に反映しなければならない (MUST)。
- **FR-005**: システムは、設定ダイアログ内にデフォルト検索オプションを公式既定値へ復元するリセット機能を提供しなければならない (MUST)。
- **FR-006**: システムは、検索結果一覧をCSVファイルとして保存するための機能を提供し、保存先ダイアログを介して指定されたパスへ保存しなければならない (MUST)。
- **FR-007**: システムは、検索結果一覧をExcelファイル (.xlsx) として保存するための機能を提供し、保存先ダイアログを介して指定されたパスへ保存しなければならない (MUST)。
- **FR-008**: システムは、エクスポート対象の検索結果が存在しない場合は保存処理を開始せず、ユーザーに通知しなければならない (MUST)。

### 主要エンティティ (Key Entities)

- **DefaultSearchOptions (デフォルト検索オプション)**:
  - `match_case`: boolean (大文字/小文字区別のデフォルト)
  - `use_regex`: boolean (正規表現使用のデフォルト)
  - `include_formula`: boolean (数式検索のデフォルト)
  - `include_shape`: boolean (Shape内テキスト検索のデフォルト)
  - `include_comment`: boolean (コメント検索のデフォルト)
  - `include_hidden`: boolean (非表示シート検索のデフォルト)
  - `extensions`: string[] (対象拡張子のデフォルトリスト)
- **ExportTask (出力タスク)**:
  - `format`: CSV または XLSX
  - `destination_path`: ユーザーが保存ダイアログで指定した絶対ファイルパス
  - `result_items`: 出力対象となる検索一致アイテムの一覧

## 成功基準 (Success Criteria) *(必須)*

### 測定可能な成果 (Measurable Outcomes)

- **SC-001**: ユーザーは設定画面から3クリック以内でデフォルトオプションの変更・保存、または初期値へのリセットを完了できること。
- **SC-002**: アプリケーション起動時および設定保存時、デフォルトオプションが遅延や画面のチラつきなく100%確実に検索バーへ反映されること。
- **SC-003**: 検索結果のエクスポート時、ファイル保存ダイアログの表示からファイル保存完了まで、ユーザーが迷うことなく100%成功裏に操作を完了できること。
- **SC-004**: 不正な設定値や空の拡張子設定が存在しても、アプリケーションがクラッシュすることなく安全に既定のフォールバック値へ自動修復されること。

## 前提条件と想定 (Assumptions)

- デフォルト設定の永続化は、ローカル環境（端末内ストレージ）に安全に保存され、外部通信は一切発生しない。
- 既存の言語設定や履歴件数設定と同じ設定ダイアログ内に「デフォルト検索オプション」セクションとして統合配置される。
- 出力時の保存先ダイアログには、OS標準のネイティブ保存ダイアログが使用される。

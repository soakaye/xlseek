# クイックスタート & 動作検証手順 (Quickstart & Validation Guide)

本ドキュメントは、「デフォルト動作設定」および「CSV/Excel出力」の検証手順をまとめたガイドです。

---

## 1. 前提条件と環境準備

- Node.js & npm インストール済み
- Rust & Cargo ツールチェーン インストール済み
- プロジェクトルートで `npm install` 実行済み

```bash
# 検証ビルド & テスト
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

---

## 2. デフォルト検索オプション検証シナリオ

### シナリオ 2.1: 初期起動時のデフォルト値確認
1. アプリケーションを起動 (`npm run tauri dev`)。
2. 画面上の検索オプションを確認：
   - 大文字/小文字を区別: **OFF**
   - 正規表現: **OFF**
   - 数式: **ON**
   - Shape内テキスト: **OFF**
   - コメント/メモ: **ON**
   - 非表示シート: **OFF**
   - 対象拡張子: **.xlsx, .xlsm, .xlsb, .xls** (全て選択中)

### シナリオ 2.2: 設定画面でのデフォルト値変更と即時同期
1. ステータスバー右下の歯車アイコン（設定）をクリックして設定ダイアログを開く。
2. 「デフォルト検索オプション」セクションで以下を変更：
   - 「数式」を **OFF** に変更
   - 「Shape内テキスト」を **ON** に変更
   - 対象拡張子から「.xlsb」を除外
3. 「保存」をクリックする。
4. 設定ダイアログが閉じ、メイン画面の検索バーに以下が即時反映されていることを確認：
   - 数式: OFF
   - Shape: ON
   - 拡張子: .xlsb が非選択状態

### シナリオ 2.3: 次回起動時の永続化反映
1. アプリケーションを一度終了する。
2. 再度アプリケーションを起動する。
3. 起動直後の検索バーのオプションが、前回の保存内容（数式: OFF, Shape: ON, .xlsb非選択）で保持されていることを確認する。

### シナリオ 2.4: 「デフォルトに戻す」リセット機能の検証
1. 再度設定ダイアログを開く。
2. 「デフォルトに戻す」ボタンをクリックする。
3. すべてのオプションが初期値（数式: ON, Shape: OFF, 全拡張子選択など）へリセットされることを確認する。
4. 「保存」をクリックし、画面も公式規定値に戻ることを確認する。

## 3. CSV / Excel エクスポート検証シナリオ

### シナリオ 3.1: 検索結果0件時のエクスポート抑止
1. 検索未実行（またはヒット0件）の状態で、ステータスバーの「CSV出力」または「Excel出力」をクリックする。
2. 保存ダイアログは開かず、「エクスポート対象の結果がありません」等のトースト通知が表示されることを確認する。

### シナリオ 3.2: CSV出力フロー
1. 任意のExcelファイルを検索し、ヒット結果が1件以上表示された状態にする。
2. ステータスバーの「CSV出力」をクリックする。
3. OS標準の保存ダイアログが開き、デフォルトファイル名（例: `ExcelGrep_Results_2026-09-28.csv`）が提示される。
4. 任意の保存先（デスクトップ等）を指定して「保存」をクリックする。
5. ファイルが正しく書き込まれ、「CSVファイルを保存しました」トーストが表示されることを確認する。
6. 出力されたCSVファイルをテキストエディタ等で開き、ヘッダーと該当セル情報が正しく出力されていることを確認する。

### シナリオ 3.3: Excel出力フロー
1. 検索結果が表示された状態で、ステータスバーの「Excel出力」をクリックする。
2. OS標準の保存ダイアログが開き、`.xlsx` 形式の保存先を選択して保存する。
3. Excelファイルが正常に出力され、完了トーストが表示されることを確認する。
4. Excelまたは互換スプレッドシートアプリで開き、内容が崩れず出力されていることを確認する。

### シナリオ 3.4: 保存キャンセル時の挙動
1. 「CSV出力」または「Excel出力」をクリックし、保存ダイアログを表示する。
2. 「キャンセル」ボタンを押下してダイアログを閉じる。
3. エラーが発生せず、画面状態が正常に維持されることを確認する。

# Feature Specification: i18n 基盤を Tauri プラグインへ移行する

**Feature Branch**: `009-migrate-tauri-i18n`

**Created**: 2026-09-26

**Status**: Draft

**Input**: User description: "i18nには、tauri-plugin-i18n を使用する構成に変更する。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 言語設定と表示を維持する (Priority: P1)

利用者は多言語対応基盤が変わった後も、従来の設定と同じ方法で日本語・英語・デフォルトを使える。

**Why this priority**: 基盤の変更によって保存済み設定や画面の読みやすさを失わせないため。

**Independent Test**: 既存版で各言語設定を保存した状態から更新版を起動し、設定画面、検索、結果、プレビュー、通知、メニュー、出力を確認する。

**Acceptance Scenarios**:

1. **Given** 日本語または英語が保存されている、**When** 更新後に起動する、**Then** 保存済み設定に従って表示され、設定画面にも同じ選択が示される。
2. **Given** デフォルトまたは未設定である、**When** 日本語環境または日本語以外の環境で起動する、**Then** それぞれ日本語または英語で表示される。
3. **Given** 検索条件、結果、通知が表示されている、**When** 設定画面で言語を切り替える、**Then** アプリが作成した文言は再起動なしで切り替わり、検索条件・結果・ファイル内容は保持される。
4. **Given** 言語設定の保存に失敗する、**When** 別の言語を選ぶ、**Then** 今回の起動中は選択が有効となり、保存失敗が現在の表示言語で通知される。

---

### User Story 2 - 翻訳の欠落時も操作できる (Priority: P1)

利用者は、選択した言語に一部の文言がない場合も、英語の文言で操作を続けられる。

**Why this priority**: 翻訳の追加・更新中でも、操作に必要な案内を欠落させないため。

**Independent Test**: 日本語の文言を一つ欠落させた状態で該当画面を開き、その文言のみ英語になることを確認する。

**Acceptance Scenarios**:

1. **Given** 日本語表示中に日本語の文言が一つ欠けている、**When** その文言を表示する、**Then** 当該文言のみ英語になり、ほかの文言と設定は変わらない。
2. **Given** 端末の言語情報が取得できない、**When** デフォルト設定で起動する、**Then** 英語で利用できる。

---

### User Story 3 - 一貫した翻訳資源で言語を追加できる (Priority: P2)

保守担当者は、表示箇所ごとに翻訳の仕組みを増やさずに文言を管理できる。

**Why this priority**: 将来の言語追加や文言修正の際に画面と出力の訳が食い違うことを防ぐため。

**Independent Test**: 表示文言の追加・変更箇所を確認し、今回の対象言語と英語への代替表示が一貫していることを確認する。

**Acceptance Scenarios**:

1. **Given** アプリが作成する文言を変更する、**When** 日英の表示を確認する、**Then** 画面、通知、メニュー、出力で同じ言語設定に従う。
2. **Given** 表示言語を日本語または英語にする、**When** 診断ログを確認する、**Then** アプリが作成するログの説明文は英語である。

### Edge Cases

- 保存済み設定が読み取れない、または不正な場合は、デフォルトとして端末言語から表示言語を決める。
- デフォルト選択中の端末言語変更は、次回起動時またはデフォルトを選び直した時に反映する。
- 切り替え中の通知・ダイアログも選択後の言語で表示する。ファイル名、検索語、セル値など利用者のデータは翻訳しない。
- 翻訳資源の読込に失敗した場合でも起動を妨げず、利用可能な英語の案内を表示する。失敗の説明を英語の診断ログに記録する。
- 外部アプリや OS の文言、第三者ライセンスの原文、外部ライブラリのログは翻訳対象外とする。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: アプリの多言語対応は、指定された `tauri-plugin-i18n` を使用する構成に変更しなければならない。対象はフロントエンドと Tauri 側でアプリが作成する翻訳対象文言とする。
- **FR-002**: 移行後も、設定画面でデフォルト・日本語・英語を選択でき、選択は再起動なしで反映されなければならない。
- **FR-003**: 移行前に保存された有効な言語設定を引き継がなければならない。保存失敗時は今回の起動中だけ選択を適用し、利用者に通知しなければならない。
- **FR-004**: デフォルトまたは未設定では、端末の優先言語が日本語なら日本語、それ以外なら英語を使用しなければならない。取得失敗時は英語を使用しなければならない。
- **FR-005**: 対象言語の文言が欠けた場合は、その文言だけ英語に代替しなければならない。翻訳資源が使えない場合も利用可能な英語で操作を継続できなければならない。
- **FR-006**: アプリが作成する画面、通知、エラー、メニュー、アクセシビリティ名、出力見出しは同じ有効言語に従わなければならない。既存の検索条件、検索結果、ファイル内容を言語変更で改変してはならない。
- **FR-007**: アプリ自身が出力する診断ログの説明文と内部エラー理由は、表示言語に関係なく英語でなければならない。
- **FR-008**: 将来の言語追加に際して、表示箇所ごとに独立した翻訳機構を追加する必要がない構成にしなければならない。今回選択可能な言語は日本語と英語に限る。

### Key Entities *(include if feature involves data)*

- **言語設定**: デフォルト・日本語・英語の利用者選択。既存の保存値を引き継ぐ。
- **表示言語**: 現在の利用者向け文言に使う言語。デフォルト時は端末言語から決まる。
- **翻訳文言**: アプリが作成する言語別の文言。欠落時は文言単位で英語へ代替する。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 既存の有効な言語設定を持つ更新確認ケースの 100% で、更新前後の表示言語が一致する。
- **SC-002**: 日本語・英語・デフォルトの切り替え確認ケースの 100% で、再起動なしに主要画面と通知が選択した言語となり、検索条件と結果が保持される。
- **SC-003**: 日本語文言の欠落、端末言語取得失敗、保存値不正、翻訳資源読込失敗の各確認ケースで、英語の案内を使って主要操作を続けられる。
- **SC-004**: 日本語と英語の各表示で、検索・結果・プレビュー・出力・設定・メニュー・エラーの確認項目の 100% が有効な表示言語、または欠落時の英語で示される。
- **SC-005**: 両表示言語で採取したアプリ自身の診断ログの説明文と内部エラー理由の 100% が英語である。
- **SC-006**: 利用者は設定画面を開いてから 30 秒以内に表示言語を切り替えられる。

## Assumptions

- この変更は既存の `008-add-language-settings` の言語切替仕様を引き継ぎ、多言語対応の基盤を変更するものである。
- 指定された `tauri-plugin-i18n` は、同名の Tauri v2 用プラグインとその対応する JavaScript パッケージを指す。具体的な版と互換性は計画段階で確定する。
- 翻訳するのはアプリが作成する文言であり、利用者のデータ、第三者ライセンス、OS および外部アプリの文言は原文を保持する。
- 診断ログの言語は利用者向け表示言語と独立している。

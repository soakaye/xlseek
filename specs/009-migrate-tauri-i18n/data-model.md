# データモデル: i18n 基盤の移行

## 言語設定（LanguagePreference）

| 項目 | 型・値 | 規則 |
|---|---|---|
| 保存キー | `exlgrep.language` | 008 から変更しない |
| 選択値 | `default` / `ja` / `en` | 不正値・読込失敗は `default` |
| 保存結果 | 成功 / 失敗 | 失敗でも今回の起動中は選択値を使う |

**状態遷移**: 起動時に保存値を検証し、有効な表示言語を解決する。変更時は先に今回の起動中の選択を反映し、保存に失敗したら通知する。次回起動時は最後に保存できた値へ戻る。

## 有効な表示言語（DisplayLanguage）

| 項目 | 型・値 | 規則 |
|---|---|---|
| 言語 | `ja` / `en` | 明示選択を優先 |
| デフォルトの解決 | 端末の優先言語 | 先頭言語が `ja` なら `ja`、それ以外・取得失敗は `en` |
| 反映範囲 | 画面、通知、エラー、メニュー、出力 | 出力は要求開始時の言語で固定 |

起動中の端末言語変更は次回起動またはデフォルト再選択まで反映しない。

## 翻訳資源（TranslationCatalog）

| 項目 | 型・値 | 規則 |
|---|---|---|
| 正本 | `src-tauri/locales/en.yml`、`ja.yml` | プラグインへ同梱。英語はフロントエンドの非常時表示にも使用。各ファイル先頭に4要素の説明コメントを置く |
| キー | 一意な文字列 | 画面・Rust の両側で同じ意味を指す |
| 言語別の値 | 表示文字列 | 英語キーは対象範囲を網羅し、日本語は欠落可能 |
| 差込値 | ファイル名などの原文 | 翻訳せず、表示時に差し込む |

**解決順**: 有効言語のキー → 英語の同じキー → 英語カタログの必須キー `common.translationUnavailable`。欠落キーそのものを利用者に表示しない。英語カタログの必須キーはカタログテストで検証する。プラグイン読込失敗時はフロントエンドで同じ `en.yml` を解析して表示する。

## 通知（Notice）

| 項目 | 型・値 | 規則 |
|---|---|---|
| 文言キー | 翻訳キー | 翻訳済み文字列は状態に保存しない |
| 差込値 | 任意の原文 | ファイル名・パスなどを保持 |
| 種別 | 成功 / 失敗 / 案内 | 既存の通知表示方式を維持 |

表示時に現在の言語で解決する。言語切替中に開いている通知も再描画され、差込値は変化しない。

## 出力要求（ExportRequest）

008 で追加した `language` を維持する。値は `ja` または `en`。未指定の旧要求は英語を既定とし、不正値は拒否する。CSV・Excel の列見出し、一致種別、シート名はこの値で翻訳し、一つの出力内で言語を混在させない。

## 診断ログ

翻訳資源と表示言語に依存しない英語の説明文を使う。検索語、セル値、ファイル内容はログ文言に差し込まない。

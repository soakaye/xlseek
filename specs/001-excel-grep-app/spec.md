## ユーザーシナリオ & テスト *(必須)*

### ユーザーストーリー 1 - 高速フォルダ横断検索と結果一覧表示 (優先度: P1)

ユーザーは検索対象のフォルダと検索キーワード（または正規表現）を指定し、対象フォルダ配下のすべての Excel ファイル（.xlsx, .xlsm, .xlsb, .xls）を一括検索して、一致したセル番地やシート名、テキスト抜粋が並ぶ結果テーブルを閲覧できる。

**この優先度である理由**: 本アプリケーションの根幹となる最重要価値であり、これ単体で Excel ファイル内のテキスト検索ツール（MVP）として成立するため。

**独立テスト方法**: 複数の Excel ファイルが含まれるフォルダを指定し、任意のキーワードで検索を実行する。一致したファイル名、シート名、セル番地、一致種別、抜粋テキストが一覧テーブルに正しく描画されることを確認する。

**受入シナリオ**:

1. **前提**: 検索対象フォルダに複数の Excel ファイルが存在する。
   **もし**: 検索入力欄にキーワードを入力し「SEARCH」ボタンを押下（または Enter キー入力）した場合、
   **ならば**: フォルダ内の全 Excel ファイルが走査され、キーワードを含む行が結果一覧テーブルに表示され、フッターにヒット件数と所要時間が表示される。
2. **前提**: 結果一覧テーブルに多数の検索結果が表示されている。
   **もし**: 結果内絞り込み入力欄にテキストを入力した場合、
   **ならば**: 一覧テーブルが即座にフィルタリングされ、入力内容に合致する行のみが表示される。

---

### ユーザーストーリー 2 - セル周辺のスプレッドシートプレビューと詳細確認 (優先度: P2)

ユーザーは結果一覧テーブルの任意の行をクリックすることで、右ペインのプレビュー領域において該当ファイルの完全なパス、数式バー、周辺セルを含めたワークシートグリッド、および詳細メタ情報を即座に確認できる。Excel アプリ本体を都度起動することなく前後の文脈を把握できる。

**この優先度である理由**: 検索結果がどの文脈・どの表の中で使われているかを即座に確認できることが、従来の単純な Grep ツールに対する大きな差別化要素となるため。

**独立テスト方法**: 検索結果一覧から特定の行をクリックし、右ペインのファイル名、シート名バッジ、独立した場所パス行、数式バー、該当セルがハイライトされたスプレッドシート、および Excel 風シートタブが正しく更新されることを確認する。

**受入シナリオ**:

1. **前提**: 検索結果一覧にヒット項目が表示されている。
   **もし**: 任意の行をクリックして選択した場合、
   **ならば**: 右ペインが更新され、上部にファイル名と「シート: [シート名]」バッジ、2行目に完全なファイルパス、数式バーにセル番地と内容、ワークシートプレビューに対象セルが強調表示された表が表示される。
2. **前提**: 右ペインにワークシートプレビューが表示されている。
   **もし**: プレビュー領域を縦または横にスクロールした場合、
   **ならば**: 列見出し（A, B, C...）および行番号ヘッダーが固定表示（sticky）され、画面端で枠線が欠けることなくスムーズにスクロールできる。
3. **前提**: ワークシートプレビューが表示されている。
   **もし**: ワークシート直下の Excel 風シートタブバーを確認した場合、
   **ならば**: 現在一致したシートがアクティブタブとしてハイライト表示され、シート名が直感的に識別できる。

---

### ユーザーストーリー 3 - 柔軟な検索オプション指定 (優先度: P3)

ユーザーは検索オプション（大文字/小文字の区別、正規表現、数式、コメント/メモ、非表示シート）のトグルを自由に切り替えることで、目的に応じた高精度な横断検索を実行できる。

**この優先度である理由**: セル値だけでなく、計算式やメモ、非表示シートに埋もれた情報を特定したいビジネスユーザーや監査担当者の高度な検索ニーズを満たすため。

**独立テスト方法**: 「正規表現」や「数式」などの各オプショントグルを ON/OFF して検索を実行し、意図した条件に合致する結果のみが抽出されることを確認する。

**受入シナリオ**:

1. **前提**: セル内に数式（例: `=SUM(B10:B12)`）を含むファイルが存在する。
   **もし**: 「数式」オプションを有効にして数式文字列を検索した場合、
   **ならば**: 一致種別が「Formula」として抽出され、数式バーおよびプレビューに該当数式が表示される。
2. **前提**: 非表示シート内にのみ対象キーワードを含むファイルが存在する。
   **もし**: 「非表示シート」オプションを有効にして検索した場合、
   **ならば**: 当該シートのセルがヒットし、一致種別「Hidden Sheet」として抽出される。
3. **前提**: 「正規表現」オプションが有効である。
   **もし**: 正規表現パターン（例: `Q[1-4]_Data`）を入力して検索した場合、
   **ならば**: パターンに一致する全セルが正確に検出される。

---

### ユーザーストーリー 4 - 外部連携および検索結果のエクスポート (優先度: P4)

ユーザーはプレビュー領域のアクションボタンから対象ファイルを直接 Excel で開いたり、保存先フォルダをエクスプローラーで開いたりできる。また、検索結果の一覧を CSV または Excel ブックとしてエクスポートできる。

**この優先度である理由**: 検索で見つかったファイルの実編集へのシームレスな移行や、検索結果を監査証跡・報告資料として外部保存できるようにするため。

**独立テスト方法**: プレビューヘッダーの「Excel で開く」「フォルダを開く」「パスをコピー」ボタンおよびフッターの「CSV エクスポート」「Excel エクスポート」ボタンを操作し、各機能が正常に作動することを確認する。

**受入シナリオ**:

1. **前提**: プレビューにファイルが選択されている。
   **もし**: 「Excel で開く」ボタンを押下した場合、
   **ならば**: OS 既定の Excel アプリケーションが起動し、該当ファイル（および対象セル番地）が開かれる。
2. **前提**: プレビューヘッダーの場所行にある「パスをコピー」ボタンを押下した場合、
   **ならば**: 対象ファイルのフルパスがクリップボードにコピーされ、通知メッセージが表示される。
3. **前提**: 検索結果が一覧に表示されている。
   **もし**: 「CSV エクスポート」または「Excel エクスポート」ボタンを押下した場合、
   **ならば**: 検索結果全件を含むファイルが出力・保存される。

### エッジケース (Edge Cases)

- **検索対象フォルダ内に Excel ファイルが存在しない場合**: エラー停止せず、0 件ヒットとして分かりやすい空状態メッセージを表示する。
- **読み込み不能な破損ファイルやアクセス権限のないファイルが存在する場合**: 該当ファイルの読み込みをスキップして検索を継続し、ステータスまたはログにスキップ理由を記録する。
- **無効な正規表現が入力された場合**: 検索実行時にエラー通知を表示し、不正な正規表現による異常終了を防止する。
- **巨大な Excel ファイルや大量のシートが存在する場合**: 検索処理中に UI がフリーズしないようバックグラウンドで並列処理し、進捗状況をプログレスバーで随時フィードバックする。
- **ウィンドウサイズが縮小された場合**: 右ペインのヘッダーにおいてアクションボタンが欠けたり、ファイルパスがボタンと重なったりせず、パス専用行として独立して表示される。

## 要件定義 *(必須)*

### 機能要件 (Functional Requirements)

- **FR-001**: システムは、ユーザーが検索対象のローカルフォルダを GUI のダイアログまたはドラッグ＆ドロップ、パス直接入力で指定できるようにしなければならない (MUST)。
- **FR-002**: システムは、指定フォルダ配下のサブフォルダを再帰的に走査し、対応する Excel 拡張子（`.xlsx`, `.xlsm`, `.xlsb`, `.xls`）のファイルを検出・検索対象としなければならない (MUST)。
- **FR-003**: システムは、入力された検索キーワードによるテキスト部分一致検索を実行できなければならない (MUST)。
- **FR-004**: システムは、検索オプションとして「大文字/小文字の区別」「正規表現」「数式 (Formula)」「コメント / メモ」「非表示シート」の ON/OFF を切り替え可能にしなければならない (MUST)。
- **FR-005**: システムは、検索実行中に進捗状況（進行率、スキャン中ステータス）を表示し、完了時にヒット件数と所要時間を表示しなければならない (MUST)。
- **FR-006**: システムは、検索結果一覧をテーブル形式で左ペインに表示し、ファイル名、シート名、セル番地、一致種別、一致テキスト抜粋（ハイライト付き）を表示しなければならない (MUST)。
- **FR-007**: システムは、検索結果一覧テーブル内の検索結果を、インクリメンタルに入力文字列で絞り込めるクイックフィルタを提供しなければならない (MUST)。
- **FR-008**: システムは、結果テーブルの行選択に応じて、右ペインに該当ファイルのプレビュー情報を即座に表示しなければならない (MUST)。
- **FR-009**: 右ペインのヘッダーは 2 行構成とし、1 行目にファイル名とシート名バッジ（「シート: [シート名]」）およびアクションボタン群（Excel で開く、フォルダを開く）、2 行目に独立した完全ファイルパス表示行（パスコピー機能付き）を配置して重なりやボタン欠けを防止しなければならない (MUST)。
- **FR-010**: システムは、プレビュー領域に Excel 数式バーを備え、選択されたセル番地およびセルの完全な内容（または計算式）を表示しなければならない (MUST)。
- **FR-011**: システムは、プレビュー領域に該当セルを中心とする周辺ワークシートグリッドを表示し、一致セルを強調枠線および背景ハイライトで表示しなければならない (MUST)。
- **FR-012**: ワークシートグリッドは固定ヘッダー（列記号および行番号）を備え、縦横スクロール可能で、スクロール時にも右辺の枠線が欠けないレイアウトでなければならない (MUST)。
- **FR-013**: ワークシートグリッド直下に Excel 風のシートタブバーを配置し、現在表示中のシートをアクティブスタイルで明示し、ブック内のシート構成を把握可能にしなければならない (MUST)。
- **FR-014**: システムは、プレビュー下部に一致セルの詳細情報（一致種別、完全テキスト、行番号、列番号、非表示状態）を表示するメタ情報カードを提供しなければならない (MUST)。
- **FR-015**: システムは、選択したファイルを外部の Excel アプリケーションで起動する機能、およびファイルの保存場所をエクスプローラーで表示する機能を提供しなければならない (MUST)。
- **FR-016**: システムは、検索結果一覧を CSV ファイルまたは Excel ブック形式で出力（エクスポート）する機能を提供しなければならない (MUST)。
- **FR-017**: システムは、不正な正規表現や破損ファイルに遭遇した際もクラッシュせず、安全にエラー処理・スキップを行わなければならない (MUST)。

### 主要エンティティ (Key Entities)

- **SearchQuery (検索条件)**:
  - 検索キーワード (Keyword)
  - フォルダパス (Target Directory)
  - オプション設定 (Match Case, Regex, Formula, Comments, Hidden Sheets)
  - 対象拡張子リスト (Supported Extensions)
- **SearchResultItem (検索結果アイテム)**:
  - 一致 ID
  - ファイル名 (File Name)
  - 完全パス (Full File Path)
  - シート名 (Sheet Name)
  - セル番地 (Cell Address, 例: A12)
  - 行番号・列番号 (Row & Column Number)
  - 一致種別 (Match Type: Cell Value / Formula / Comment / Hidden Sheet)
  - 一致抜粋テキスト (Snippet / Highlighted Text)
  - セル完全内容 (Full Content)
  - 数式文字列 (Formula String)
  - 周辺セルグリッド情報 (Surrounding Grid Matrix)
  - ブック内シート一覧 (Sheet Names List)
- **ScanProgress (走査進捗)**:
  - スキャン状態 (Scanning / Completed / Error)
  - 処理済みファイル数 / 総ファイル数
  - ヒット件数合計
  - 経過時間 (秒)

## 成功基準 *(必須)*

### 測定可能な成果 (Measurable Outcomes)

- **SC-001**: ユーザーはフォルダ指定から検索開始までを 3 ステップ以内の操作で行うことができ、迷いなく検索を実行できること。
- **SC-002**: 100 ファイル（合計 100MB 規模）の Excel ファイル群に対する検索において、初期検索結果の表示開始まで数秒以内で応答すること。
- **SC-003**: 検索結果一覧から任意の行を選択した際、右ペインのプレビュー（数式バー・グリッド・シートタブ・メタ情報）が 100 ミリ秒以内に遅延なく切り替わること。
- **SC-004**: 検索結果テーブルおよびプレビュー領域において、ウィンドウサイズ（幅 1160px 等）に関わらずボタンの欠けやパスの重なり、右辺ボーダーの断ち切れが 0 件であること。
- **SC-005**: 検索結果全件のエクスポート（CSV / Excel）を実行した際、一覧に表示されている全データが欠落なく正確に出力されること。
- **SC-006**: 読み込み不可能なファイルや不正なファイルが混在していても、アプリケーション全体のクラッシュ率が 0% であり、処理可能なファイルの結果を確実に表示できること。

## 前提条件と想定 (Assumptions)

- **実行環境**: 主な想定環境は Windows OS のデスクトップ環境であり、Tauri による軽量デスクトップアプリケーションとして提供される。
- **Excel アプリ連携**: 「Excel で開く」機能は、OS にインストールされた規定の表計算ソフトウェア（Microsoft Excel 等）が関連付けられていることを前提とする。
- **暗号化ファイル**: パスワードで保護・暗号化された Excel ファイルは、初期バージョンでは解析スキップの対象とし、エラーや警告として記録する。
- **プレビューのスコープ**: プレビュー領域のワークシートグリッドは、該当セルの周辺文脈を素早く確認するための高速プレビュービューアであり、セル値の編集や書式編集を行う機能は本スコープ外とする。

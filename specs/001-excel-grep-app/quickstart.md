**機能ブランチ**: `001-excel-grep-app`

## 1. 前提条件 (Prerequisites)

- **Node.js**: v18 以上 (推奨 v20+)
- **Rust / Cargo**: 最新 stable (Rust 1.77+ 推奨、v1.98 確認済み)
- **OS**: Windows 10/11 (WebView2 ランタイムインストール済み)
- **ビルドツール**: C++ Build Tools (Visual Studio Build Tools)

---

## 2. セットアップ手順 (Setup Commands)

プロジェクトルートにて以下のコマンドを実行します。

```bash
# 1. フロントエンド依存パッケージのインストール
npm install

# 2. Rust クレート依存関係の事前ビルド確認
cargo check --manifest-path src-tauri/Cargo.toml

# 3. 開発モードでの起動 (フロントエンドホットリロード + Tauriアプリ起動)
npm run tauri dev
```

## 3. エンドツーエンド検証シナリオ (E2E Validation Scenarios)

### シナリオ 1: フォルダ指定と高速横断検索の検証 (P1)

1. **手順**:
   - アプリ起動後、「フォルダを選択」ボタンを押下してテスト用 Excel ファイル（.xlsx, .xlsm, .xlsb）が格納されたフォルダを指定する。
   - 検索入力欄にキーワード（例: `Financial Report`）を入力し、`Enter` キーまたは「SEARCH」ボタンを押下する。
2. **期待される結果**:
   - 検索中、プログレスバーが進捗し、ヒットした行が左ペインの結果一覧テーブルに順次ストリーミング追加される。
   - 走査完了後、ステータスバーに「Found XX matches in YY files (0.ZZs)」と表示される。
   - 結果内絞り込み欄に入力すると、表示一覧が即座にフィルタリングされる。

---

### シナリオ 2: セルプレビューと固定ヘッダー・シートタブの検証 (P2)

1. **手順**:
   - 検索結果テーブルから任意のセル（例: `A12`）をクリックする。
2. **期待される結果**:
   - 右ペインのヘッダーにファイル名と「シート: [シート名]」バッジが表示され、2 行目に完全なファイルパスが表示される。
   - 数式バーにセル番地と値/計算式が表示される。
   - ワークシートプレビューに、該当セルを中心とする前後 3 行・前後 2 列程度の表が高速描画され、対象セルがエメラルド枠線＋黄色ハイライトで強調される。
   - ワークシートを縦横にスクロールしても、列見出し（A, B, C...）および行番号ヘッダーが `sticky` で固定され、右辺枠線が欠けない。
   - ワークシート直下のシートタブバーに、該当シートがアクティブタブとしてハイライト表示される。

---

### シナリオ 3: 検索中断 (CANCEL) の動作検証 (P3)

1. **手順**:
   - 大量のファイルが含まれるフォルダを対象に検索を開始する。
   - 検索実行中、「CANCEL」ボタンを押下する。
2. **期待される結果**:
   - バックグラウンド走査が安全に停止し、アプリがフリーズしたりクラッシュしない。
   - 中断時点までに取得された検索結果が一覧テーブルに保持され、行選択によるプレビュー確認が正常に行える。

---

### シナリオ 4: 外部連携およびファイルパスのコピー (P4)

1. **手順**:
   - プレビュー上部ヘッダーの「パスをコピー」アイコンボタンを押下する。
   - 「フォルダを開く」アイコンボタンを押下する。
   - 「Excel で開く」ボタンを押下する。
2. **期待される結果**:
   - クリップボードにファイルのフルパスがコピーされ、「パスをコピーしました」通知が表示される。
   - OS のエクスプローラーが起動し、該当ファイルが選択された状態で表示される。
   - 既定の Microsoft Excel アプリケーションが起動し、該当ブックが開かれる。

---

### シナリオ 5: 結果エクスポートの検証 (P4)

1. **手順**:
   - フッターの「CSV エクスポート」および「Excel エクスポート」ボタンを押下する。
   - 保存先ダイアログでファイル名を指定して保存する。
2. **期待される結果**:
   - 出力された CSV ファイルをテキストエディタおよび Excel で開いた際、文字化け（BOM対応確認）なく全件のデータが出力されている。
   - 出力された XLSX ファイルが Excel で正常に開き、ファイル名・シート・セル番地・一致テキストが整然と記録されている。

# Quickstart & Verification Guide: UI項目調整 (UI Adjustments)

## 概要
本ガイドは、UI項目調整で実装された各機能・操作制御が正しく動作することをエンドツーエンドで確認するための手順と検証シナリオを記載する。

---

## 前提条件
- Node.js (v18以上) および npm
- Rust ツールチェーン (`cargo`)
- Google Chrome または Safari (macOS)

---

## 検証シナリオ一覧

### シナリオ 1: 検索キーワード入力欄における日本語入力(IME)確定Enterの検証
1. ブラウザで [design/mainui/index.html](file:///Users/soakaye/Develop/Projects/workspaces/exgrep/fixui/design/mainui/index.html) を開く（または Tauri アプリ `npm run tauri dev` を起動）。
2. `#searchInput`（検索キーワード入力欄）にフォーカスを当て、日本語IMEをONにする。
3. `しはんき` と入力し、スペースキー等で `四半期` に変換する。
4. **Enterキーを押下して変換を確定する。**
   - **期待結果**: 文字列 `四半期` が確定されるのみで、**検索は開始されない**（SEARCHボタンがCANCELに切り替わらず、進捗バーも動かない）。
5. 変換確定後、もう一度 **Enterキーを押下** する。
   - **期待結果**: 検索処理が即座に開始され、SEARCHボタンがCANCELに切り替わり、進捗バーが動き出す。

---

### シナリオ 2: フォルダパス入力欄におけるEnterキー無効化の検証
1. `#folderInput`（フォルダパス入力欄）をクリックしてフォーカスを当てる。
2. 日本語で `けいり` と入力して `経理` に変換確定する。
   - **期待結果**: 確定処理が正常に完了し、検索は走らない。
3. 続けて、非IMEの状態で **Enterキーを押下** する。
   - **期待結果**: 検索処理は開始されない。入力フォーカスはフォルダ入力欄内に維持される。
4. 参照ボタン（フォルダアイコン）をクリックし、ダイアログ呼び出しトーストが表示されることを確認する。

---

### シナリオ 3: 検索対象拡張子トグル選択の検証
1. 検索バー右下の拡張子ボタン群（`.xlsx`, `.xlsm`, `.xlsb`, `.xls`）を確認する。
2. `.xlsb` をクリックする。
   - **期待結果**: `.xlsb` が非選択状態（暗い背景色）になり、検索対象から除外される。
3. 続けて `.xlsx`, `.xlsm` をクリックして解除し、残り1つ（`.xls`）のみにする。
4. 残り1つの `.xls` をクリックする。
   - **期待結果**: 選択解除が拒否され、最低1つの拡張子が常に有効な状態が維持される。

---

### シナリオ 4: ステータスバー進捗バーの配置と探索中フェーズの検証
1. 検索キーワード入力欄で Enter を押下するか、`SEARCH` ボタンをクリックする。
2. 開始直後のステータスバー表示を確認する。
   - **期待結果**:
     - プログレスバーがメッセージの手前（左側）に固定幅（`w-44`）で配置されている。
     - インジケーターがオレンジ色で点滅し、「探索中」「フォルダスキャン中: {パス}」が表示される。
3. 350ms後のファイル走査フェーズを確認する。
   - **期待結果**: プログレスバーがエメラルド色になり、「60% (件数/総数)」「ファイル解析中: ...」と表示される。
4. 完了時の表示を確認する。
   - **期待結果**: インジケーターが緑点灯になり、「100%」「完了: {件数} 件一致」が表示される。

---

### シナリオ 5: 周辺セルプレビューグリッドの縦横スクロールと固定見出しの検証
1. 検索結果リストから1行目（`Q3_Summary.xlsx`）を選択する。
2. 右ペインの周辺セルプレビューグリッド（`#spreadsheetGridContainer`）を確認する。
3. **縦スクロールの検証**:
   - マウスホイールまたはスクロールバーで下方向へスクロールする。
   - **期待結果**: 30行以上（行8〜行40）のデータがスムーズにスクロールし、最上部の列見出し行（`A, B, C...`）および左上の `#` 見出しが常に上端に固定表示（Sticky）されている。
4. **横スクロールの検証**:
   - 右方向へスクロールする。
   - **期待結果**: 左端の行番号列（`8, 9, 10...`）および `#` 見出しが常に左端に固定表示されている。
5. **セル選択と数式バー連動**:
   - 任意の下部セル（例: 行22の `1,030,000`）をクリックする。
   - **期待結果**: セルが選択枠で強調され、数式バーの名前ボックスに `F22`、内容ボックスに `=SUM(C22:E22)` が即座に反映される。

## 自動検証コマンド

```bash
# 1. HTMLモックの構文エラー検証
python3 -c "import html.parser; p = html.parser.HTMLParser(); p.feed(open('design/mainui/index.html').read()); print('HTML Parser: OK')"

# 2. フロントエンド TypeScript型チェック & Viteビルド
npm run build

# 3. バックエンド Rustユニットテスト
cargo test --manifest-path src-tauri/Cargo.toml
```

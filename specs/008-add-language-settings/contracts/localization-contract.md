# 契約: 表示言語、通知、Tauri 境界

## 言語の決定と設定画面

- 表示言語コードは `ja` と `en`。保存キーは `exlgrep.language` とし、設定値 `default`・`ja`・`en` を有効とする。
- 起動時は保存済み設定を採用する。`default`・未設定・不正値・読み取り失敗時は端末言語を取得する。端末の言語タグが `ja` または `ja-*` なら `ja`、それ以外と取得失敗時は `en`。デフォルトの選択時も端末言語を取得し、起動中の端末言語変更は次回起動時に反映する。
- 設定画面はステータスバーの名前付きボタンから開き、現在の設定と表示言語、およびデフォルト・日本語・英語の選択肢を常に表示する。デフォルトのラベルは日本語表示時に `デフォルト`、英語表示時に `Default` とし、ほかの選択肢は `日本語`・`English` とする。キーボードで選択でき、Esc と閉じるボタンで閉じられる。
- 言語変更は即時に画面へ反映し、検索状態を維持する。保存失敗時も今回の設定と表示言語は維持し、最後に保存できた設定またはデフォルトへ次回戻ることを通知する。
- 通知は `message_key` と差し込み値を保持し、表示時の言語で文を生成する。表示中に言語が変わったらその通知も更新する。

## Rust との境界

### コマンド失敗

コマンドが利用者へ返す失敗は JSON オブジェクト `{ "code": ErrorCode }` とする。`ErrorCode` は `invalid_regex`、`path_not_found`、`workbook_open_failed`、`preview_failed`、`export_failed`、`app_launch_failed`、`folder_open_failed`、`permission_denied`、`search_failed`、`internal_error` を最低限含む。既知の原因は具体的なコードに分類し、その他は `internal_error` とする。フロントエンドは未知コードにも選択言語の汎用エラーを表示する。OS や外部ライブラリの生文言を利用者向けの JSON に含めない。

### 検索進捗イベント `scan-progress`

既存の `state`、`scanned_files`、`total_files`、`matches_found`、`elapsed_ms` は保持する。追加する `phase` は `preparing`、`discovering`、`scanning`、`finished` のいずれかとする。`current_file` は実際のフォルダ名またはファイル名だけを持ち、ない場合は空文字列とする。失敗時のみ `error_code` に `ErrorCode` を入れる。画面は現在の言語で進捗文を組み立て、イベント内に翻訳済みの固定文言を入れない。

### 出力要求 `export_results`

既存の `request` に `language: "ja" | "en"` を追加する。Rust 側は値を検証し、CSV と Excel の列見出し、一致種別、Excel シート名をその言語で出力する。利用者が検索した元データは変更しない。無効値は `internal_error` として拒否し、意図しない言語でファイルを作らない。

### アプリメニュー `set_menu_locale`

`language: "ja" | "en"` を受け取り、macOS のアプリ作成メニューの見出し、About、定義済み項目のラベルを更新する。アプリ起動後に表示言語が確定した時点、および利用者が切り替えた時点で呼び出す。他の対象 OS では成功として扱う。失敗した場合は英語ログに記録し、画面には選択言語の操作案内を表示する。

## 文言とログの境界

- アプリの画面文言、アクセシビリティ用名称、通知、進捗、エラー、出力見出しは有効な表示言語を使う。対象言語のキーが欠けている場合はその文言だけ英語辞書を使い、設定やほかの文言は変えない。英語辞書は全キーを持つことを検証する。
- アプリが書く診断ログの固定文とアプリ起因のエラー理由は英語を使う。ログの文字列は画面辞書から取得しない。
- 検索語と Excel セル内容をログへ出さない。ファイル名やパスなど元データ、OS ダイアログ、第三者ライセンス本文、外部ライブラリ自身のログは翻訳対象外とする。

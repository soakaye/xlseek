# Feature Specification: 表示言語の自動選択と設定画面

**Feature Branch**: `008-add-language-settings`

**Created**: 2026-09-26

**Status**: Draft

**Input**: User description: "現在日本語版のみであるが、日本語以外の環境では英語のメッセージ類を出力する。設定画面を設け日本語と英語の切り替えを可能とする。将来的には多言語対応可能とする。ログ出力は英語で行う。"

## Clarifications

### Session 2026-09-26

- Q: 言語設定の保存に失敗した場合はどう表示しますか？ → A: 今回の起動中は選んだ設定に従い、保存失敗を通知する。次回起動時は最後に保存できた設定を使い、保存済み設定がなければデフォルトとして端末言語から選ぶ。
- 言語設定に「デフォルト」を設ける。選択中は端末の優先言語から表示言語を決め、対象言語に文言がない場合はその文言だけ英語を使う。
- Q: 言語設定が「デフォルト」のまま、アプリ起動中にシステム言語を変更した場合、表示はいつ切り替えるべきですか？ → A: 次回起動時、または「デフォルト」を選び直した時に切り替える。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 環境に合った表示言語で起動する (Priority: P1)

初めて利用する人は、端末の言語が日本語なら日本語、それ以外なら英語でアプリの案内やエラーを読める。

**Why this priority**: 手動設定前でも、日本語を使わない利用者が検索操作とエラー対応を行えるようにするため。

**Independent Test**: 保存済みの言語設定がない状態で、日本語環境と日本語以外の環境からそれぞれ起動し、検索画面、検索中の通知、失敗時の案内を確認する。

**Acceptance Scenarios**:

1. **Given** 保存済みの言語設定がなく端末の優先言語が日本語、**When** アプリを起動する、**Then** アプリが作成する表示文言は日本語になる。
2. **Given** 保存済みの言語設定がなく端末の優先言語が日本語以外、**When** アプリを起動する、**Then** アプリが作成する表示文言は英語になる。
3. **Given** 英語でアプリを利用している、**When** 検索またはファイル操作でエラーが発生する、**Then** 利用者への説明と対処案内は英語で表示される。

---

### User Story 2 - 設定画面で表示言語を切り替える (Priority: P1)

利用者は設定画面で「デフォルト」「日本語」「English」を選び、デフォルトでは端末の言語に従い、日英の明示選択時は選んだ言語でアプリを使い続けられる。

**Why this priority**: 端末の言語と利用者がアプリで読みたい言語は一致するとは限らないため。

**Independent Test**: 設定画面でデフォルト・日英を切り替えて表示の反映、検索状態の維持、再起動後の設定保持を確認する。

**Acceptance Scenarios**:

1. **Given** アプリを表示している、**When** 設定画面を開く、**Then** 現在の設定と表示言語、および「デフォルト」（英語表示時は「Default」）「日本語」「English」の選択肢が分かる。
2. **Given** 日本語表示で検索条件や検索結果がある、**When** 設定画面で「English」を選ぶ、**Then** 再起動なしで表示文言が英語になり、検索条件と結果は維持される。
3. **Given** 英語表示である、**When** 設定画面で「日本語」を選ぶ、**Then** 再起動なしで表示文言が日本語になる。
4. **Given** 利用者が日本語または英語を選び保存に成功した、**When** アプリを再起動する、**Then** 端末の言語に関係なく選択した言語で表示される。
5. **Given** 利用者が「デフォルト」を選ぶ、**When** 端末の優先言語が日本語またはそれ以外でアプリを起動・再起動する、**Then** それぞれ日本語または英語で表示される。
6. **Given** 言語設定の保存に失敗した、**When** アプリを使い続ける、**Then** 今回選んだ設定に従って表示し、保存されなかったことを現在の表示言語で通知する。
7. **Given** 言語設定の保存に失敗した、**When** アプリを再起動する、**Then** 以前に保存できた設定を使い、保存済み設定がなければデフォルトを使う。

---

### User Story 3 - 言語に左右されない診断ログを得る (Priority: P2)

問題を調査する担当者は、利用者の表示言語に左右されず、アプリ自身が出力したログを英語で読める。

**Why this priority**: 言語ごとに異なるログ文言を突き合わせる負担をなくすため。

**Independent Test**: 日本語表示と英語表示の両方で同じ操作とエラーを発生させ、アプリ自身が出力するログの説明文が英語であることを確認する。

**Acceptance Scenarios**:

1. **Given** 表示言語が日本語、**When** アプリが処理状況やエラーを記録する、**Then** ログの説明文は英語で記録され、画面の案内は日本語で表示される。
2. **Given** 表示言語が英語、**When** 同じ処理を行う、**Then** ログの説明文は英語で記録され、画面の案内も英語で表示される。

### Edge Cases

- 端末の言語情報が取得できない場合は英語を表示する。
- 端末の優先言語が日本語の地域違いなら日本語、それ以外の言語や英語の地域違いなら英語を表示する。
- 保存済みの言語設定が読み取れない、または未対応の値になっている場合は、端末言語による自動選択を適用し、起動を妨げない。
- 有効な表示言語に対応する文言が欠けている場合、その文言だけ英語を表示し、ほかの文言や言語設定は変えない。
- 言語設定の保存に失敗した場合は、選んだ設定を今回の起動中に限り使用し、現在の表示言語で保存失敗と次回起動時の設定・表示言語を知らせる。
- 言語切り替え中に表示されている通知、ダイアログ、検索結果の見出しは選択後の言語に更新する。ファイル内容、検索語、セル値、ファイル名は変えない。
- 外部アプリやOSが生成するダイアログ文言、第三者ライセンスの原文、外部ライブラリが生成するログは翻訳対象に含めない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 言語設定が「デフォルト」または未設定の場合、アプリは端末の優先言語が日本語なら日本語、それ以外なら英語を表示言語として選ばなければならない。
- **FR-002**: アプリはどの表示言語でも到達できる設定画面を提供し、現在の設定と表示言語、およびデフォルト・日本語・英語の選択肢を示さなければならない。日本語・英語の選択肢はそれぞれ「日本語」「English」と表記し、デフォルトは表示言語に応じて「デフォルト」または「Default」と表記しなければならない。
- **FR-003**: 利用者が設定画面で言語を選ぶと、アプリは再起動を求めずに表示文言を更新し、入力中の検索条件、検索結果、選択状態を維持しなければならない。
- **FR-004**: アプリは利用者が選んだ言語設定を保存しなければならない。保存済みの「日本語」「English」は端末言語より優先し、「デフォルト」は起動時に端末言語から表示言語を決めなければならない。
- **FR-005**: アプリは自身が作成する画面文言、メニュー、設定項目、操作案内、進捗表示、通知、エラー、確認メッセージ、アクセシビリティ用の名称、および出力ファイルの見出しを有効な表示言語で提示しなければならない。対象言語の文言が欠けている場合は FR-009 に従う。
- **FR-006**: アプリは利用者に表示するエラーを有効な表示言語で説明しなければならない。エラー発生元の文言をそのまま表示して、表示言語と異なる案内にしてはならない。対象言語の説明が欠けている場合は英語を使わなければならない。
- **FR-007**: アプリ自身が出力する診断ログの説明文とアプリ起因のエラー理由は、選択言語に関係なく英語にしなければならない。
- **FR-008**: アプリは言語情報や保存済み設定の取得に失敗しても利用でき、未対応または不正な設定値には FR-001 の自動選択を適用しなければならない。
- **FR-009**: アプリは表示文言を言語ごとに管理し、対象言語に文言がない場合はその文言だけ英語で表示しなければならない。将来の追加言語を加えても既存の日英の表示と保存済み設定を維持しなければならない。今回選べる表示言語は日本語と英語に限る。
- **FR-010**: 言語設定の保存に失敗した場合も、アプリは今回の起動中は選んだ設定に従って表示し、現在の表示言語で保存失敗を通知しなければならない。次回起動時には最後に保存できた設定を使用し、保存済み設定がない場合はデフォルトを使用しなければならない。

### Key Entities *(include if feature involves data)*

- **表示言語**: アプリが利用者向けの文言に使用する言語。今回の対応値は日本語と英語。
- **言語設定**: 「デフォルト」「日本語」「English」の選択。デフォルトと未設定時は端末の優先言語から表示言語を決める。保存に失敗した選択は今回の起動中だけ有効となる。
- **表示文言**: 画面、通知、エラー、出力見出しなどでアプリが利用者に示す言語別の文言。
- **診断ログ**: 問題調査のためアプリ自身が記録する処理状況やエラーの説明。表示言語の設定とは独立する。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 新規利用時、日本語環境と日本語以外の環境の両方で、起動直後の表示言語が想定どおりとなる確認ケースの成功率が100%である。
- **SC-002**: 利用者は設定画面を開いてから30秒以内に表示言語を切り替えられ、再起動せずに画面の文言を確認できる。
- **SC-003**: 日本語と英語のそれぞれで、主要操作（検索、結果確認、プレビュー、出力、設定、アプリのメニュー、エラー確認）の文言が対象言語で表示される。対象言語の文言を欠落させた確認ケースでは、その文言だけ英語で表示される。
- **SC-004**: 日本語または英語への変更と保存に成功した確認ケースの100%で、再起動後も選択した表示言語が保持され、検索条件と結果が言語変更だけで失われない。
- **SC-005**: 日本語表示と英語表示の両方で発生させた代表的な操作ログとエラーログについて、アプリ自身の説明文とエラー理由の英語率が100%である。
- **SC-006**: 言語設定の保存に失敗させた確認ケースの100%で、今回の起動中は選択した設定に従い、保存失敗と次回起動時の設定・表示言語を利用者に通知する。
- **SC-007**: デフォルトを保存した確認ケースの100%で、端末言語を変更して再起動すると表示言語が追随する。

## Assumptions

- 端末の優先言語は、言語設定がデフォルトのときに起動時とデフォルト選択時に取得する。起動中の端末言語変更は次回起動時に反映する。明示的に選んだ日本語・英語は端末言語変更の影響を受けない。
- 今回は日本語と英語の2言語を提供する。第三の言語の翻訳作成と選択画面への追加は将来の対象とする。
- 翻訳対象はアプリ自身が作成する文言であり、利用者のデータ、検索対象のExcel内容、第三者の法的文書、OSや外部アプリの文言は原文を保持する。
- プロジェクト憲章 v2.0.0 の「指定言語の優先と自然な出力」原則に従い、英語の製品表示とログには指定された英語を使用する。

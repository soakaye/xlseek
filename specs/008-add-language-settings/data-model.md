# データモデル: 表示言語の自動選択と設定画面

## 表示言語 `AppLanguage`

| 属性 | 値 | 制約 |
|---|---|---|
| 言語コード | `ja`、`en` | 今回の有効な表示言語。未対応値は受け付けない |
| 表示名 | `日本語`、`English` | 設定画面では自言語表記で固定 |

端末から得た言語タグは先頭の言語部分を判定する。`ja` と `ja-*` は `ja`、それ以外と取得不能時は `en` とする。将来の対応言語追加時は既存の `ja`・`en` の意味と保存値を変えない。

## 言語設定 `LanguagePreference`

| 属性 | 型 | 制約 |
|---|---|---|
| 保存済み設定 | `default`・`ja`・`en` または未設定 | 保存に成功した選択だけを保持。未設定は `default` と同じ動作 |
| 今回の設定 | `default`・`ja`・`en` | 設定画面で選択中の値。保存失敗後も今回の起動中は選択値を保つ |
| 今回の表示言語 | `AppLanguage` | 設定が `default` なら端末言語、`ja`・`en` なら設定値から決定 |
| 保存状態 | 成功・失敗 | 失敗時は今回の設定と表示言語だけを更新し、保存済み設定は変えない |

状態遷移: 起動時は保存済み設定を検証し、有効なら採用する。保存値の読み取り失敗・不正値・未設定時は `default` として端末言語から決める。利用者が切り替えると今回の設定と表示言語を即時更新し、保存に成功すれば保存済み設定を更新する。保存に失敗すれば現在の表示言語で通知し、次回起動は最後に保存できた設定、なければデフォルトから決める。デフォルトの端末言語は起動時とデフォルト選択時に取得する。

## 表示文言 `LocalizedMessage`

| 属性 | 型 | 制約 |
|---|---|---|
| キー | 固定識別子 | 英語辞書はアプリ作成文言の全キーを持つ |
| 言語別文言 | 文字列または差し込み可能な形式 | 対象言語にキーがなければ、その文言だけ英語辞書から作る |
| 差し込み値 | 件数・経過時間・ファイル名など | 利用者データは翻訳しない |

アプリ名、パス、Excel 内のセル値、第三者ライセンス本文は翻訳対象から除外する。表示中のトーストはキーと差し込み値を保持し、言語変更時に再描画する。

## エラー `AppError`

| 属性 | 型 | 制約 |
|---|---|---|
| コード | 固定の `ErrorCode` | コマンド失敗と検索進捗の失敗に共通 |
| 診断内容 | 英語のログ本文 | 利用者向け表示には含めない |

Rust 側の失敗はコードへ分類し、詳細を英語で記録する。画面はコードから選択言語の説明を選ぶ。未知コードの場合も選択言語の汎用エラーを表示する。OS・外部ライブラリが返す原文は画面へ連結しない。

## 検索進捗 `ScanProgress`

既存の状態、走査数、一致数、経過時間は維持する。表示専用の日本語を `current_file` に混ぜず、処理段階、実ファイル名、失敗時のエラーコードを分離する。画面はこの値と現在の表示言語から進捗文を作るため、検索中の切り替えにも追随できる。

## 出力要求 `ExportRequest`

既存の形式・保存先・検索結果に有効な `AppLanguage` を加える。CSV と Excel は同じ言語の見出し、一致種別、シート名を使用する。検索結果のファイル名、パス、シート名、セル値、数式は原文を保持する。

## 診断ログ

表示言語に依存しない英語のアプリ作成文と、必要な診断値からなる。ユーザーの検索語や Excel セル内容をログへ出さない。外部ライブラリの出力はアプリ作成文の翻訳対象外とする。

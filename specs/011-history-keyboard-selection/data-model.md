# Data Model: 履歴一覧の操作状態

保存データの形式は変更しない。[既存の履歴モデル](../010-search-history-path-completion/data-model.md)にある検索テキスト履歴と検索ディレクトリ履歴を表示する。

| 状態 | 内容 | 条件 |
|---|---|---|
| 表示対象 | 閉じている／検索テキスト履歴／検索ディレクトリ履歴／既存のディレクトリ補完 | 一度に表示する一覧は 1 つ |
| 表示項目 | 対象の履歴に保存された順序付き文字列 | 0～50 件。値の重複は既存の履歴管理が防ぐ |
| 現在項目 | フォーカスされ、確定対象になる項目 | 表示項目に含まれる場合だけ有効。空一覧では存在しない |
| 入力値 | 検索テキストまたは検索ディレクトリの現在値 | 確定時だけ対応する入力欄を更新する |

## 状態遷移

| 操作 | 表示・フォーカス | 入力値・検索 |
|---|---|---|
| 履歴ボタンで表示 | 対応する履歴を開く。項目フォーカスはまだない | 変更しない |
| ボタンから Tab／下矢印 | 先頭項目へ移る。空なら Tab は通常の次の操作対象へ進む | 変更しない |
| 項目から下矢印／上矢印 | 次／前の項目へ移り、両端では留まる | 変更しない |
| 項目から Tab | 次の項目へ移り、末尾から先頭へ戻る。1 件なら同じ項目に留まる | 変更しない |
| 項目から Enter | 現在項目を確定し、一覧を閉じる | 対応する入力欄だけ更新し、検索は開始しない |
| 項目から Escape | 一覧を閉じ、対応する入力欄へ戻る | 変更しない |
| 一覧外のクリック | 一覧を閉じる | 変更しない |
| 表示中に項目数が減少 | 存在しない項目へのフォーカス・確定を避ける | 変更しない |
| IME 変換中 | 履歴移動・確定を行わない | IME の入力を妨げない |

`現在項目` は画面内の一時状態であり、履歴に保存しない。新しい外部データや識別子は追加しない。

# UI Contract: 履歴一覧のキーボード操作

対象は検索テキストと検索ディレクトリの履歴。両方で同じキー操作を提供する。履歴の順序と保存条件は[既存契約](../../010-search-history-path-completion/contracts/search-history-path-contract.md)に従う。

| 開始位置 | 操作 | 結果 |
|---|---|---|
| 履歴ボタン | Enter | 対応する履歴一覧を表示する |
| 開いた履歴のボタン | Tab または下矢印 | 先頭項目へフォーカスを移す。0 件なら Tab は通常どおり次へ進む |
| 履歴項目 | 下矢印／上矢印 | 1 項目ずつ移る。末尾／先頭では留まる |
| 履歴項目 | Tab | 次の項目へ移り、末尾から先頭へ戻る。1 件なら同じ項目に留まる |
| 履歴項目 | Enter | 項目を対応する入力欄へ反映し、一覧を閉じる。検索は開始しない |
| 履歴項目 | Escape | 入力値を変えずに一覧を閉じ、対応する入力欄へフォーカスを戻す |
| 一覧外 | クリック | 入力値を変えずに一覧を閉じる |

現在の項目は視覚的に識別でき、フォーカスと選択状態の表示は一致する。日本語入力の変換・確定中のキーは履歴操作へ転用しない。履歴の表示中に項目が減った場合、存在しない項目は選択できない。ディレクトリ補完候補の操作は既存契約のままとする。
